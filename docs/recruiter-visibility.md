# Recruiter visibility checklist

## GitHub
- Pin `rep-monitor-case-study` on your profile (GitHub profile → Customize your pins).
- Keep the source repositories private unless authorized for publication.
- Add **screenshots only with fictional users, addresses, asset identifiers and customer names**.
- If publishing the prototype through Pages, verify its URL before adding it to the README.

### Short description (English)
Technical case study documenting my hands-on work on an enterprise equipment-monitoring solution, spanning Flutter, Next.js, FastAPI, PostgreSQL, Google Cloud and operational integrations. Includes architecture, engineering decisions and sanitized independent examples. Production systems and customer data remain private.

Estudo de caso técnico sobre minha atuação no desenvolvimento e integração de uma plataforma corporativa de monitoramento, envolvendo Flutter, Next.js, FastAPI, PostgreSQL, Google Cloud e automação. ## Before interviews
Be ready to distinguish what you personally implemented from collaborative work. Avoid making unverified quantitative claims, and demonstrate the mockup as an **illustrative prototype**, not a live customer environment.
