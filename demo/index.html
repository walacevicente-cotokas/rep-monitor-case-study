Why it matters

From signal to action

Field service workflow

  1. Look up asset by REP or serial.
  2. Check current collection status and the latest observation.
  3. Confirm customer/location context.
  4. Request revalidation using an authorized backend operation.
  5. Review the refreshed state.

Note: This public demo does not send real revalidation requests.

Technical decisions

  • Separate ERP records from monitoring telemetry.
  • Review imports to avoid accidental reactivation.
  • Preserve selected state transitions for historical analysis.
  • Limit the field map to relevant problem locations.
  • Enforce authorization at the API boundary.
