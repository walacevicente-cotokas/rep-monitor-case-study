# Public interactive portfolio prototype

Open [index.html](index.html) locally in a browser to explore an original, dependency-free illustration of the platform. It contains an overview, searchable sample devices, a deliberately abstract location view and an engineering workflow.

**Every device, number, status and place is invented.** This is not a screenshot, clone, or production client; it does not authenticate, use real maps, contact external servers, or execute revalidation.

## GitHub Pages (optional)

To host the demo, configure GitHub Pages to publish from **main / root**, then link to `/demo/` on the resulting Pages URL. Pages is not enabled by committing this directory. Verify repository settings and published content before sharing with recruiters.

## Recruiter walkthrough (60 seconds)

1. Open the overview and describe the operational problem.
2. Search for `DEMO-102`; explain why stale telemetry matters.
3. Show the abstract problem-location concept and explain clustering and map performance.
4. Read the workflow and describe the client → API → database separation.
5. Jump to the full case study for decisions, stack and clearly marked sanitized examples.
