# Independently authored code samples

These files are **illustrations using invented data and model names**, not snippets copied from a private codebase.

- `status_normalization.py`: simple time-aware status classification and edge-case handling.
- `status_summary.sql`: a parameter-free aggregation example using PostgreSQL `FILTER` and an interval.

The actual system has additional business rules, access controls and error handling not reproduced here. These examples are intended for discussion in interviews, not deployment.
